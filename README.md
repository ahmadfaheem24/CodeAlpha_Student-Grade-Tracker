# 🎓 Student Grade Tracker – Java

A simple **console-based Student Grade Tracker** developed in Java.

</div>

---

## ✨ Features

- 👨‍🎓 Add multiple student records
- 📝 Store student names and scores using `ArrayList`
- 📊 Calculate average score
- 🏆 Find the highest score
- 📉 Find the lowest score
- 📋 Display a complete student grade report
- 💻 Simple and beginner-friendly console interface

---

## 🛠️ Technologies Used

- **Java**
- **ArrayList**
- **OOP Concepts**
- **Scanner**
- **Console Interface**

---

## 🎯 Project Purpose

This project was created to strengthen Java programming fundamentals, including:

- Classes and Objects
- ArrayList
- Loops
- Conditional Statements
- User Input
- Basic Data Processing
